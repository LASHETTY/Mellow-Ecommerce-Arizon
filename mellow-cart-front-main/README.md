
# Mellow - Fashion E-Commerce Store

## Project Overview

Mellow is a responsive fashion e-commerce platform built with modern web technologies.

## Features

- Responsive design that works on mobile, tablet, and desktop
- Home page with hero section and featured products
- Product listing page with dynamic product loading
- Mini cart functionality with add/remove capabilities
- Full cart page with quantity adjustment
- Persistent cart data using localStorage

## Technologies Used

- Vite
- TypeScript
- React
- React Router
- React Query
- Tailwind CSS
- shadcn/ui components

## Getting Started

### Prerequisites

- Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Installation

```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate to the project directory
cd mellow-fashion

# Install dependencies
npm install

# Start the development server
npm run dev
```

## Project Structure

- `/src/components` - Reusable UI components
- `/src/pages` - Page components for different routes
- `/src/context` - React context for state management
- `/src/hooks` - Custom React hooks
